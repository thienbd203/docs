# Laravel Documentation - Tiếng Việt

Đây là thư mục chứa bản dịch tài liệu Laravel Framework sang tiếng Việt.

## 📁 Cấu trúc thư mục

```
docs-vi/
├── README.md                    # File này
├── installation.md              # Bản dịch installation.md
├── configuration.md             # Bản dịch configuration.md
├── ...                          # Các file dịch khác
└── progress.md                  # Theo dõi tiến độ dịch
```

## 🚀 Cách sử dụng

### Dịch file mới:
1. Copy file từ `docs-src/` sang `docs-vi/`
2. Đổi tên file (nếu cần) hoặc giữ nguyên
3. Dịch nội dung theo quy tắc trong `../TRANSLATION_RULES.md`
4. Commit và push

### Cấu trúc file:
- Giữ nguyên tên file với bản gốc (ví dụ: `installation.md`)
- Để dễ dàng map giữa bản gốc và bản dịch
- Có thể thêm metadata ở đầu file nếu cần

## 📊 Tiến độ

Xem file `progress.md` để theo dõi tiến độ dịch thuật chi tiết.

## 🔗 Liên kết

- Bản gốc: `../docs-src/`
- Quy tắc dịch thuật: `../TRANSLATION_RULES.md`
- Kế hoạch dịch thuật: `../TRANSLATION_PLAN.md`

## 🤝 Contributing

Khi dịch file mới:
1. Đọc và hiểu `../TRANSLATION_RULES.md`
2. Check `../TRANSLATION_PLAN.md` để biết priority
3. Dịch theo quy tắc và checklist
4. Update file `progress.md`
5. Submit pull request
