# Tài liệu Laravel

Bạn có thể tìm thấy phiên bản online của tài liệu Laravel tại [https://laravel.com/docs](https://laravel.com/docs)

## Hướng dẫn đóng góp

Nếu bạn đang gửi tài liệu cho **phiên bản ổn định hiện tại**, hãy gửi đến branch tương ứng. Ví dụ, tài liệu cho Laravel 12 sẽ được gửi đến branch `12.x`. Tài liệu dành cho phiên bản Laravel tiếp theo nên được gửi đến branch `master`.
